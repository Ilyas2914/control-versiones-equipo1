# control-versiones-equipo1

![CI](https://github.com/Ilyas2914/control-versiones-equipo1/actions/workflows/ci.yml/badge.svg)

Repositorio de prácticas de Despliegue de Aplicaciones Web de 2º DAW. El proyecto sirve para aprender a trabajar en equipo utilizando Git y GitHub.

## Funcionalidades

- Ficha personal de cada integrante del equipo.
- Control de versiones con Git.
- Colaboración mediante ramas y Pull Requests.

## Requisitos

- Tener Git instalado.
- Tener un navegador web moderno.
- Tener una cuenta de GitHub.

## Cómo ejecutarlo en local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Ilyas2914/control-versiones-equipo1.git
   cd control-versiones-equipo1
   ```

2. Abre la carpeta con Visual Studio Code.
